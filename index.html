What this does / assumptions
  • Keeps only events located at JMCC (any room), KE 1st & 3rd floors, Bepler, and Campbell.
  • Setup Time uses the report's "Setup Starts" time; if none is given, it falls back to the "Setup Ready By" time and says so in the cell.

  • Events split across a page break in the PDF (same reference number twice) are merged into one row.
